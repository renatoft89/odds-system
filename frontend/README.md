# Odds System - Frontend React + Vite

Este diretório contém o frontend (Interface do Usuário) em React SPA do **Odds System**. Ele foi estruturado utilizando Vite para HMR extremamente rápido e Vanilla CSS customizado de alta fidelidade visual.

---

## 🚀 Como Executar o Frontend Localmente

1. Garanta que o servidor backend Express esteja em execução na porta `3000`.
2. Certifique-se de estar dentro desta pasta:
   ```bash
   cd frontend
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
5. Abra o link indicado no console (ex: `http://localhost:5173/` ou pelo IP local).
